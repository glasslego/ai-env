# 문서 작업의 LLM Wiki 검색·등록

## 적용

- 재사용할 설계·기술 설명·리서치·회고·세션 요약을 작성하거나 갱신할 때 적용한다.
- Jira·Wiki·Agit 결과물은 기존 작성·게시 절차를 유지한다. 실제 게시 요청이 있을 때만 게시한다.
- 권한 없는 원격 문서나 개인정보를 추가 수집하지 않는다. 확인한 로컬 Markdown만 등록한다.
- 시스템 지침(`AGENTS.md`, `CLAUDE.md`, `SKILL.md`, rules)·템플릿·코드·단순 링크 수정·임시 출력은 등록하지 않는다.

## 실행 경로

- CLI: `uv run --directory /Users/megan/work/glasslego/ai-env ai-env wiki ...`.
- Vault: `OBSIDIAN_BASE`, 미설정이면 `~/Documents/Obsidian Vault`. 다른 Vault는 `wiki --vault "경로" ...`로 지정한다.
- 로컬 파일만 처리하며 외부 LLM 호출·서버·백그라운드 감시는 없다.

## Vault 규칙

- Vault 문서를 다루기 전에 Vault `AGENTS.md`, `wiki/index.md`, `wiki/운영 가이드.md`를 읽는다. 종합 절차·상태 전환은 운영 가이드가 정본이다.
- 공용 작업 기록(`00_session/<저장소명>/agent-logs/`)은 work·review·fix 완료 보고만 ingest 후보다. checkpoint·summary는 등록하지 않는다.
- 작업 기록은 gzip 보관 전에 스냅샷으로 등록되므로 원본 안내 노트로 바뀌어도 근거가 유지된다.

## 작성 전 — 검색

1. 주제의 핵심어 2~4개로 `ai-env wiki search "핵심어" --limit 5`를 실행한다. 위 실행 경로를 사용한다.
2. 결과의 `path`를 Vault 기준으로 열고, 관련 종합·출처를 실제로 읽는다. 검색 결과를 사실의 근거로 대체하지 않는다.
3. 결과가 없거나 관련성이 부족하면 MOC·원본 검색으로 보완한다. 이 CLI는 전체 Vault 검색이나 의미 검색이 아니다.
4. 종합의 미검토 상태·출처 변경·적용 환경을 확인한다. 기존 판단과 다른 근거는 병기한다.
5. 등록 후 바뀐 Vault 내부 원본은 `source_changed`로 표시된다. 원본을 다시 읽고 재등록한 뒤 근거의 변경을 반영한다.

## 작성 후 — 등록·종합

1. 사용자 요청에 따라 완성한 로컬 Markdown에 `ai-env wiki register "절대경로.md"`를 실행한다.
2. 외부 문서는 `00_inbox/llm-wiki/`에 내용 해시별 스냅샷으로 보관된다. 등록 원본은 수정하지 않는다.
3. `registered`면 `related_pages` 중 관련 종합 최대 3개를 읽고, 새 결론·반증·범위 변화만 반영한다.
4. 종합의 `source`에 `snapshot`의 확장자를 뺀 Vault 상대 위키링크를 추가한다. 해시는 코드가 등록부에 관리하므로 종합 노트에 수동 해시 필드를 만들지 않는다.
5. 이전 외부 스냅샷을 새 근거로 대체했다면 현재 종합의 출처를 갱신하고 이전 근거는 로그에 남긴다. 스냅샷 파일은 삭제하지 않는다.
6. `wiki/index.md`, `wiki/log.md`, `synthesized_at`을 실제 변경에 맞게 갱신한다. 검토·상태 전환은 Vault `wiki/운영 가이드.md`의 최신 규칙을 따른다. 사용자 검토를 AI가 대신 완료 표시하지 않는다.
7. `unchanged`면 원본 재등록으로 로그를 늘리지 않는다. 다만 종합 반영이 누락됐거나 사용자가 요청한 경우 근거를 확인해 보완한다.
8. 관련 종합이 없으면 기존 정본과 비교해 반복 활용 가치가 있는 질문에만 새 페이지를 만든다. 등록만으로 페이지를 무조건 생성하지 않는다.
9. `skipped`는 종합·메타·스냅샷 자체의 재등록 방지다. 이를 외부 경로로 복사해 우회하지 않는다.

## 경계와 실패

- 기준 원본은 Obsidian Markdown. 기존 개념 정본·직접 작성한 해석은 별도 요청 없이 덮어쓰지 않는다.
- `2026_경력관리/`는 읽기만 한다. `40_개인/`, `41_투자_재테크/`는 사용자가 지정한 문서만 `--allow-private`로 등록한다. 기본 검색에서는 계속 제외된다.
- 검색·등록 실패 시 문서 결과는 보존하고 실패를 보고한다. 미등록을 등록 완료로 표시하지 않는다.
- 출처 등록과 종합 완료는 별개다. 최종 보고에는 필요한 경우 각각의 실제 결과를 구분한다.
- 원격 게시·메시지 전송·커밋 권한은 이 규칙에서 추가하지 않는다.
